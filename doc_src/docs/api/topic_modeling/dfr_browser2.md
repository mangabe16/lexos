
# DFR Browser 2

<a href="https://github.com/scottkleinman/dfr-browser2" target="_blank">DFR Browser 2</a> is web-based topic modelling browser that provides interactive visualizations and analysis tools for exploring topic models generated by <a href="https://mimno.github.io/Mallet/topics.html" target="_blank">MALLET</a>. DFR Browser 2 is based on Andrew Goldstone's original <a href="https://github.com/agoldst/dfr-browser" target="_blank">dfr-browser</a>. It reproduces all the major functionality of the original, but with an entirely new architecture and additional features. For full documentation, see the <a href="https://github.com/scottkleinman/dfr-browser2" target="_blank">DFR Browser 2</a>.

The `dfr_browser2` module provides a small helper class `Browser` that automates the steps required to prepare and open a a DFR Browser 2 distribution. This helper is designed to be used programmatically from Python and can be used to produce a small static browser bundle. It performs the following functions:

- Validates that all required MALLET output files exist
- Copies a template DFR Browser 2 folder into a working browser folder
- Copies all MALLET output and metadata files into the browser's `data/`, along with an optional file containing the documents used to generate the topic model.
- Manages configuration settings for the browser.
- Starts a simple HTTP server to serve the browser and opens it in a web browser.
