# README

## Generating Windows

Here is some sample code to demonstrate how to use the `Windows` class.

```python
import spacy
from lexos.rolling_windows import Windows

nlp = spacy.load("en_core_web_sm")
doc = nlp("This is a sentence. This is another sentence.")

# Create a Windows object
windows = Windows()

# Call it with data
rw = windows(input=doc, n=100, window_type="tokens", output="tokens")

# The output is a generator
print(list(rw))
```

There is an additional `alignment_mode` parameter that can be used to specify how the windows should be aligned. How character windows (`window_type="characters"`) snap to token boundaries.

If output is set to "tokens", the windows will be a list of spaCy Token or Span objects (depending on the input). If it is set to strings, these will be converted to string format.

The class takes strings, spaCy Doc objects, and lists of strings as input. It will also take lists of spaCy Span and Token objects. The former is good for handling sentences in a Doc.

The `n` parameter specifies the size of the window. If the `window_type` is "tokens", the window will be `n` tokens long. If the `window_type` is "characters", the window will be `n` characters long.

## Calculating Rolling Windows Data

To calculate rolling windows data, you import a calculator and feed it an instance of a `Windows` object.

```python
from lexos.rolling_windows.calculators import Averages

averages = Averages(
    patterns="pattern_to_match",
    windows=rw,
    output="tokens"
    mode="exact", # The search method to use ('regex', 'spacy_rule', 'multi_token', 'multi_token_exact').
    case_sensitive=False, # Whether to make searches case-sensitive.
    alignment_mode="strict", # Whether to snap searches to token boundaries. Values are 'strict', 'contract', and 'expand'.
    model="en_core_web_sm" # The language model to be used for searching spaCy tokens/spans.
)
```

The "exact" mode will search for exact matches of the pattern in the window. The "regex" mode will search for regular expression matches of the pattern in the window. The "spacy_rule" mode will search for spaCy rule matches of the pattern in the window. The "multi_token" mode will search for multi-token matches of the pattern in the window. The "multi_token_exact" mode will search for multi-token exact matches of the pattern in the window.

In most cases, you will want to work with the output data in table by calling `averages.to_df()`. This will return a pandas DataFrame with the data. This is the standard input format for Rolling Windows plotters.

## Plotting Rolling Windows Data

It is possible to plot Rolling Windows data directly from the pandas DataFrame generated by the calculator. However, the Rolling Windows module comes with a set of plotters that can be used to generate plots with a set of helpful configuration variables.

```python
from lexos.rolling_windows.plotters import SimplePlotter

plotter = SimplePlotter()
plotter.plot(averages.to_df())
```

The `SimplePlotter` class generates a static image using `matplotlib`. The `SimplePlotter` class has a number of configuration variables that can be set to customize the plot. The `SimplePlotter` class also has a `save` method that can be used to save the plot to a file. There is also a `PlotlyPlotter` class that generates an interactive plot using `plotly`. Both plotters have options to display milestones generated by the `milestones` module.
