
# DFR Browser 2

[DFR Browser 2](https://github.com/scottkleinman/dfr-browser2) is web-based topic modelling browser that provides interactive visualizations and analysis tools for exploring topic models generated by [MALLET](https://mimno.github.io/Mallet/topics.html). DFR Browser 2 is based on Andrew Goldstone's original [dfr-browser](https://github.com/agoldst/dfr-browser). It reproduces all the major functionality of the original, but with an entirely new architecture and additional features. For full documentation, see the [DFR Browser 2 repository](https://github.com/scottkleinman/dfr-browser2).

The [`dfr_browser2`](dfr_browser2.md) module provides a small helper class `Browser` that automates the steps required to prepare and open a a DFR Browser 2 distribution. This helper is designed to be used programmatically from Python and can be used to produce a small static browser bundle. It performs the following functions:

- Validates that all required MALLET output files exist
- Copies a template DFR Browser 2 folder into a working browser folder
- Copies all MALLET output and metadata files into the browser's `data/`, along with an optional file containing the documents used to generate the topic model.
- Manages configuration settings for the browser.
- Starts a simple HTTP server to serve the browser and opens it in a web browser.
